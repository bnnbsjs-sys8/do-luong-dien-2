Bảng Công Thức Trọng Tâm Kỹ Thuật Đo Lường Điện (TEE0327)

Chương 1 & 2: Sai số & Đặc tính thiết bị đo

  • Thang đo (Span): Sx = xmax − xmin
  • Độ nhạy tĩnh: K = Δy / Δx ; Độ lệch nhạy theo nhiệt độ: ΔK / ΔT = |KT2 − KT1| / |T2 − T1|
  • Độ trôi điểm không theo nhiệt độ: Δy0 / ΔT (khi x = 0)
  • Ngưỡng nhạy & Độ phân giải: ε = (D% · Sx) / 100 ; Khả năng phân ly: R = Sx / ε
  • Hàm truyền thiết bị đo so sánh: y = [KT / (1 + KT·KN)] · x
  • Sai số tiêu thụ công suất Ampe kế: γI = [RA / (Rt + RA)] · 100% ≈ (RA / Rt) · 100%

Chương 3: Gia công kết quả đo

  • Sai số tuyệt đối từ cấp chính xác: Δx = (Class% × Sx) / 100
  • Sai số tương đối tại giá trị đo x: βx% = (Δx / x) × 100%
  • Kết quả phép đo: xr = x ± Δx
  • Phép đo gián tiếp (R = U/I, P = U·I): βy = √(βU2 + βI2) ; Δy = y · βy
  • Phép đo thống kê (n lần): x̄ = (∑xi)/n ; s = √[∑(xi − x̄)2 / (n − 1)] ; sx̄ = s / √n

Chương 4 & 6: Mạch xử lý tín hiệu & Đo Dòng - Áp

  • Khuếch đại đảo: uout = −(R2/R1)·uin ; Không đảo: uout = (1 + R2/R1)·uin
  • Khuếch đại vi sai đối xứng: Uout = (R2/R1)·(U2 − U1)
  • Mạch cộng đảo: Uout = −R4·(U1/R1 + U2/R2 + U3/R3)
  • Mạch chuyển đổi U → I (Howland): Iout = −[R2 / (R1·R3)] · uin
  • Mạch Shunt dòng DC: Iout = [RS / (RA + RS)]·Iin ⇒ I = IA·(1 + RA/RS)
  • Mạch phân áp tần số cao: Dùng cuộn cảm KTL ≈ L2/(L1 + L2) ; Dùng tụ điện KTL ≈ C1/(C1 + C2)
  • Máy biến dòng (BI) & Biến áp (BU): I = KI·IA ; U = KU·UV ; ΔI = √[(KI·ΔIA)2 + (IA·ΔKI)2]

Chương 5, 7, 8 & 9: Cảm biến, Công suất & Cầu đo

  • Biến trở thẳng / tròn: Rx = R·(x/l) ; Rtđ = (R − Rx) + (Rx // Rv)
  • Tenzo & Cầu bán phần: ΔR/R0 = K·(Δl/l0) ; Ura = −EN·(ΔR / 2R0)
  • Cân băng định lượng: Q = (W · R) / L (kg/phút) ; LVDT: Ura = S · x
  • Công suất & Điện năng: P1p = U·I·cosφ ; P3p = √3·UdIdcosφ = W1 + W2 ; tanφ = √3·(W1 − W2)/(W1 + W2)
  • Công tơ qua BI, BU: Ethực = KI · KU · Eđọc ; Số vòng quay N = A · E (vòng)
  • Cầu Wheatstone & Kelvin: Rx = (R1·R3)/R2 (hoặc (R2·R3)/R1 tùy vị trí nhánh)
  • Cầu AC cuộn cảm: Rx = R2R3/R1, Lx = R2L3/R1 ; Tụ điện: Rx = R2R3/R1, Cx = R1C3/R2
  • Cầu Maxwell-Wien (mẫu C1 // R1): Rx = R2R3/R1 ; Lx = R2R3C1
